# 01 7日間ロードマップ — 「美しい風景を走る1台の車」

## 今週のゴール（これ以外は全部捨てる）

> **美しい風景の中を、気持ちよく走れる車が1台ある。**

1本の道、1台の車、最高の光。これで成立します。
**街を作らない。車種を増やさない。ミッションを作らない。** 広げた瞬間に1週間では終わりません。

### 正直な話：GT7 / GTA5 との差はどこにあるか

| 要素 | 1週間で届くか | なぜ |
|---|---|---|
| **絵の綺麗さ（1枚のスクショ）** | ✅ **かなり届く** | Lumen + Nanite + Fabの写実アセット。ここは既にAAA級の道具が無料で手に入る |
| マップの広さ・量 | ❌ 無理 | GTA5のマップは数十人×数年 |
| アニメーションの質 | ❌ 無理 | モーションキャプチャと専門職の領域 |
| 最適化（安定60fps） | ❌ 無理 | 専門技術。今週は fps が落ちても気にしない |
| ゲームとしての面白さ | ❌ 無理 | 設計と反復。今週は「走って気持ちいい」まで |

**だから「絵の綺麗さ」に全振りします。** そこだけは本当に届くので。

## Day 2 — 光（★最重要日）

**やること**: ライティングとポストプロセスだけ。アセットは一切追加しない。

1. **Before のスクショを撮る**（`ue5/review/day2_before.png`）← 必ず先に撮る
2. [`../scripts/setup_lighting.py`](../scripts/setup_lighting.py) を実行して土台を一括配置
   - Directional Light（太陽）
   - Sky Atmosphere（空）
   - Sky Light（環境光）
   - Exponential Height Fog（大気の霞）
   - Volumetric Cloud（雲）
   - Post Process Volume（露出・色）
3. Claude Codeと対話しながら調整:
   - 太陽の角度（Rotation の Y を -10〜-25度あたり。**低い太陽ほど映画的**）
   - 色温度
   - Fog の密度（遠景に薄く霞をかけると一気に奥行きが出る）
   - Post Process の **露出を固定**（後述）
   - Color Grading（コントラスト、彩度、シャドウの色）
4. **After のスクショを撮る**（`ue5/review/day2_after.png`）

### 初心者が必ず引っかかる罠：オートエクスポージャー

UE5は既定で「自動露出」がONです。カメラを暗い方に向けると勝手に明るくなり、明るい方を向くと勝手に暗くなる。
**これが「なんか安っぽい」の最大の原因です。**

Post Process Volume の `Min Brightness` と `Max Brightness` を**同じ値**にすると露出が固定され、
写真のように「明るい場所は明るく、暗い場所は暗い」画になります。`setup_lighting.py` はこれを設定済みです。

**完了判定**: before/after を並べて、**明らかに別物に見える。**
アセットは1つも増えていないのに、です。ここで「UE5すごい」となるはずです。

**辛口レビュー1回目** → [`04-rubric.md`](04-rubric.md)

## Day 3 — 舞台（走る場所を作る）

1. **Fab** で無料の環境アセットを探す（エディタ内の Fab タブから直接インポートできる）
   - 検索キーワード: `landscape`, `road`, `nature`, `megascans`
   - Quixel Megascans はUEユーザー向けに無料枠が大きいので、まずそこから
2. Landscape を作るか、取り込んだ環境アセットを配置
3. **道を1本だけ**敷く（直線＋緩いカーブで十分。サーキットを作ろうとしない）
4. Nanite が効いているか確認（ビューポート左上 → 表示 → Nanite Visualization）

**完了判定**: 走れる道があり、その周りに風景がある。

> **時間が溶ける注意点**: Fabのアセット選びは楽しすぎて何時間でも溶けます。**1時間でタイマーを切ってください。**

## Day 4 — 車の見た目

1. 車のマテリアルを **Material Instance** で調整（原型のMaterialは触らない。理由は [`02-minimum-knowledge.md`](02-minimum-knowledge.md)）
   - カーペイント: Base Color / **Metallic** / **Roughness** / Clear Coat
   - **Roughness を下げると磨かれた塗装に、上げるとマットになる。** ここの効きが一番大きい
2. ホイールとタイヤの質感
3. ガラスの反射と透過
4. 余裕があれば Fab / Sketchfab から別の車体モデルを導入

**完了判定**: 車のアップのスクショが「それっぽい」。

---

## Day 5 — 挙動（★Claude Codeが最も活きる日）

ここは**全部が数値の調整**です。つまりClaude Codeの独壇場。

1. [`../scripts/dump_vehicle_settings.py`](../scripts/dump_vehicle_settings.py) で現在の設定を書き出す
2. そのテキストをClaude Codeに渡して、狙いを言葉で伝える:
   - 「もっと低回転からトルクが出て、ドンと出る感じにして」
   - 「ハンドルを切ったときの反応が鈍い。もっとクイックに」
   - 「コーナーで簡単に滑りすぎる。グリップを上げて」
3. Claude が調整すべきパラメータと値を提案 → 反映 → **走って確かめる**
4. 気持ちよくなるまで繰り返す

**触る主なパラメータ**: エンジントルクカーブ、最大RPM、ギア比、最終減速比、
サスペンションの硬さ／ストローク、タイヤの摩擦係数、ステアリング角度カーブ、車体重量と重心位置

**完了判定**: 走らせて「気持ちいい」と自分が思える。**ここは数値では測れないので、あなたの感覚が唯一の基準です。**

## Day 6 — 演出（「ゲームの画面」にする）

1. **チェイスカメラに追従ラグを付ける**（Spring Arm の Camera Lag）
   → カメラが車をワンテンポ遅れて追う。**これだけで一気にGTっぽくなります**
2. 速度連動FOV（速いほど視野が広がる＝速度感が出る）
3. コックピット視点への切り替え
4. 速度計HUD（Widget Blueprint。Claude Codeに作らせる）
5. モーションブラー
6. エンジン音（Fab か 無料音源サイトから）
7. **TSR または DLSS を有効化**（画質を保ったままfpsが上がる）

**完了判定**: 録画して見返したとき「ゲームの映像」に見える。

## 各Day共通のルール

| ルール | 理由 |
|---|---|
| **1日の最初にスクショ、最後にスクショ** | 進捗が目に見える。モチベーションの燃料になる |
| **その日のテーマ以外を触らない** | Day3に挙動をいじり始めると必ず破綻する |
| **毎日 `git commit`** | 壊しても戻れる安心が、大胆な実験を可能にする |
| **レビューは1日1回、ラウンド上限2回** | 理由は [`03-token-rules.md`](03-token-rules.md) |
| **詰まったら30分で切り上げてチャットに投げる** | 一人で2時間溶かすのが一番もったいない |
