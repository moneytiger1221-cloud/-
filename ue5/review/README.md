# review — スクリーンショット置き場

各Dayの before / after をここに置きます。辛口レビューの入力になります。

## 命名規則

```
day2_before.png
day2_after.png
day3_before.png
...
```

## 撮り方

1. UE5のビューポートを見せたい画角に合わせる
2. `../scripts/capture_screenshot.py` の `LABEL` を書き換えて実行
3. `Saved/Screenshots/` に出た画像をここにコピー

## なぜ必要か

グラフィックの評価は、絵を見ないと成立しません。
文章だけでは「空の青が浅い」「路面の反射が死んでいる」といった指摘が出てきません。

もう一つ、**Day1 と Day7 を並べたときの差が、そのまま自分の成果の証明になります。**
毎日撮ってください。5秒で終わります。
